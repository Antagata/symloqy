# Demo script (60–90 seconds)

A storyboard for a screen recording. Use a demo Gmail account and a demo sheet with made-up words, never the real ones.

| # | Time | Screen | Voice-over / on-screen text |
|---|---|---|---|
| 1 | 0:00–0:08 | Title card: **Symloqy**, with the line "a voice-first language lab where Claude is your sparring partner" | "Vocabulary apps teach you to *recognise* words. This one makes you *use* them, out loud." |
| 2 | 0:08–0:30 | Phone or desktop Claude voice chat. The learner says "Start my Symloqy call." Claude: "Twelve words are due. Let's start with one." A short exchange follows: Claude gives a definition, the learner hesitates, Claude gives a clue, the learner gets the word and makes a sentence, Claude refines it. | Caption: *"Retrieval first, clue second, answer last."* |
| 3 | 0:30–0:40 | The learner says "lock it" a few times. Cut to Gmail: a new **Symloqy — Session Log** email arrives, with its `NEW:` / `REVIEW:` / `LINK:` lines. | "Every five words, the coach emails a structured log. If the call drops, nothing is lost." |
| 4 | 0:40–0:55 | Time-lapse caption "Next morning, 05:30". The scheduled routine's run view, then the **Symloqy — Due** email in the inbox: header counts, the numbered list, a `SURPRISE` word, `NEXT NEW WORDS`. | "A scheduled Claude routine replays every log, applies the spaced-repetition rules and sends today's list. There is no server code." |
| 5 | 0:55–1:10 | Google Sheet: the **Schedule** tab (stage, next due, last grade), then the **Sentences** tab. Type a new word into the **Words** tab. | "The sheet is just a view. Gmail is the source of truth, so the whole state can be rebuilt from the logs." |
| 6 | 1:10–1:25 | Architecture diagram from [ARCHITECTURE.md](ARCHITECTURE.md), with the three parts highlighted one by one. | "Two agents with separate jobs, an event log, and a hand-written MCP server for saving sentences." |
| 7 | 1:25–1:30 | End card: the repo link and "Experiment running: results in docs/EXPERIMENT.md". | — |

**Recording tips**
- Record the voice part in one take. Short pauses make it feel real.
- Blur or crop every address bar, email address and sheet URL.
- Keep the Due email open for no more than 2 seconds, since it contains the answers.
